# 트레이 메뉴와 요약 창 (surface brief)

Mode: Operate. 메인 창과 같은 세계(DESIGN.md)를 물려받는 확장이며 새 세계를 만들지 않는다.
대상: 메인 창을 닫거나 최소화한 채 감시를 이어 가는 개발자. 할 일: 지금 감시 중인지, 무엇이 방금 바뀌었는지 한눈에 확인하고, 일시 정지하거나 메인 창의 변경 내용으로 바로 간다.
구조(사용자 제공 참고 이미지 기준): 제목+상태, 감시 폴더, 최근 변경 목록(이벤트·파일명·시각), 하단 [감시 폴더 변경] [일시 정지].
결정: Ubuntu AppIndicator는 클릭 시 네이티브 메뉴만 띄운다 → 1) 네이티브 메뉴(시스템 Yaru 테마, 우리가 스타일하지 않음)에 상태·경로·최근 변경 3건·요약 열기·메인 창 열기·일시 정지·감시 폴더 변경·종료, 2) "요약 열기"로 화면 오른쪽 위에 장식 없는 작은 창(GtkWindow, 360px)을 연다. 이벤트 색은 메인 창 규칙(빨강=생성·증가, 파랑=삭제·감소, 노랑=선택·포커스, 모든 이벤트에 기호). 이미지의 초록 상태 배지와 수정=파랑은 따르지 않는다.
트레이 아이콘 상태: 감시 중(폴더+점), 일시 정지(폴더+정지 막대), 오류·넘침(폴더+느낌표). 단색 symbolic 아이콘.
요약 창 상태: 감시 중, 일시 정지됨, 최근 변경 없음, 대기열 넘침 후 재검사.
산출물: `docs/design/prototype/tray.html`(시안). ?view=menu | summary | paused | empty 로 상태 미리보기.
행 클릭 → 메인 창을 열고 그 파일을 선택해 변경 내용 패널을 보여 준다.
