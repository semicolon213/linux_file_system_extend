# FileScope PRD

제품 목적, 사용자, 범위, 릴리스 계획. 기능 ID와 비기능 목표는 docs/SRS.md, 제품 맥락과 시각 방향은 루트 PRODUCT.md·DESIGN.md(사용자 소유)가 정본이다.

## 1. 목적과 사용자

Ubuntu 22.04/24.04 LTS용 C17/GTK3 네이티브 파일 탐색기. 일반 사용자, 개발자, 시스템 관리자가 대상이다. 외부 터미널과 IDE의 파일 변경을 새로고침 없이 확인하고 안전하게 파일 작업을 수행한다.

## 2. 핵심 시나리오와 성공 기준

핵심 시나리오: 프로젝트 열기 → 감시 등록 → 외부 파일 생성/수정/이동/삭제 → 목록과 이벤트 로그 갱신 → 보관된 버전 비교 및 복원.

성공 기준: P0 요구사항 및 품질 게이트 통과, 실제 Ubuntu에서 GUI 데모, 성능 기준 환경과 측정 결과 기록. P1~P3는 단계별 릴리스. 전체 시스템 감시·완전한 복구·악성코드 차단을 보장하지 않는다.

## 3. 릴리스 계획

R0 공통 계약·빌드·테스트 하네스 → R1 탐색/CRUD/감시/작업 큐 → R2 이력/검색/미리보기/휴지통 → R3 디스크/개발 도구/자동화/백업 → R4 실험 기능. 각 릴리스는 적용 가능한 게이트와 독립 QA 통과 후 승인.

- R1 화면 범위와 미배정 P0 ID의 릴리스 배정은 사용자 결정 U-1, U-9(harness/PROGRESS.md 결정 기록)를 따른다.
- 단계별 모듈 도입(R1 core·job·fs·mon·nav·dash·ui, R2 his·src·pre·trash)은 docs/ARCHITECTURE.md §6.
