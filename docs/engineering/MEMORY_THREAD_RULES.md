# 메모리 및 동시성 공통 계약
공개 API는 borrowed/owned/transfer-full 여부를 명시한다. 큐에 전달하는 이벤트는 불변 복사본 또는 명시적 참조 카운트로 관리한다. 큐 소비자가 소유권을 인수하는지 계약에 정의한다. mutex 보유 중 UI 호출·장시간 I/O 금지. 잠금 순서를 설계 문서에 고정한다. 큐는 상한과 포화 정책을 갖고 유실 시 재동기화 요청을 발행한다. 종료 시 신규 작업 차단 → 감시 중지 → worker 취소/합류 → 큐 정리 → DB 종료 순서를 검증한다. UI 콜백은 수명 종료된 객체를 참조하지 않도록 취소 또는 참조 관리한다.
