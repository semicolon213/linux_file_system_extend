# FileScope PRD
Ubuntu 22.04/24.04 LTS용 C17/GTK3 네이티브 파일 탐색기. 일반 사용자, 개발자, 시스템 관리자가 대상이다. 외부 터미널과 IDE의 파일 변경을 새로고침 없이 확인하고 안전하게 파일 작업을 수행한다.
핵심 시나리오: 프로젝트 열기 → 감시 등록 → 외부 파일 생성/수정/이동/삭제 → 목록과 이벤트 로그 갱신 → 보관된 버전 비교 및 복원.
성공 기준: P0 요구사항 및 품질 게이트 통과, 실제 Ubuntu에서 GUI 데모, 성능 기준 환경과 측정 결과 기록. P1~P3는 단계별 릴리스. 전체 시스템 감시·완전한 복구·악성코드 차단을 보장하지 않는다.
