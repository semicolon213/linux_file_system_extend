# FileScope 개발 문서
Ubuntu C17/GTK3 프로젝트의 제품·설계·하네스 문서 패키지. 기존 파일은 비교 후 병합한다.
1. AGENTS.md → docs/product/PRD.md → FEATURE_SPEC.md → SRS.md
2. docs/architecture/ 계약 승인; 시각 디자인은 사용자 제공 후 적용
3. harness/tasks/000-bootstrap.md로 실제 실행 하네스 구축
4. 기능별 task 작성 및 독립 QA
현재 소스와 실행 스크립트는 포함하지 않는다. 모든 기능과 검증은 계획/NOT_RUN 상태이며 실제 저장소에 맞춰 R0에서 확정한다.

## UI/UX 디자인 권한
- 시각 디자인은 사용자가 Impeccable을 통해 별도로 제작한다. 에이전트는 색상, 타이포그래피, 간격, 레이아웃, 아이콘, 애니메이션, 테마 및 디자인 시스템을 임의로 정의하거나 변경하지 않는다.
- UI 기능 요구사항, 접근성, 상태 전달, GTK 바인딩 및 동작 테스트는 유지한다. 디자인 미제공 시 화면 스타일을 확정하지 말고 기능 로직과 인터페이스를 구현한다.
- 사용자가 제공한 디자인을 승인된 기준으로 적용하며 변경이 필요하면 먼저 승인을 요청한다. QA는 기능과 접근성을 검증하고 시각 디자인을 직접 수정하지 않는다.
