# 품질 게이트
| 게이트 | 예정 실행 명령 | 통과 기준 |
|---|---|---|
| G1 빌드 | make build | 종료 코드 0, 프로젝트 코드 경고 없음 |
| G2 단위 | make test | 관련 테스트 전체 성공 |
| G3 통합 | make integration | 실제 임시 파일 시스템 시나리오 성공 |
| G4 스타일·의존성 | make format-check lint architecture | 위반 없음 |
| G5 메모리 | make asan ubsan | sanitizer 오류 없음 |
| G6 동시성 | make tsan | 관련 모듈 경쟁 상태 없음 |
| G7 GUI | make e2e | Xvfb 실행, 사용자 시나리오 및 캡처 검증 |
| G8 부하 | make stress benchmark | 합의된 기준 충족 |
G1~G4는 모든 구현 작업에 필수. G5는 C 코드 변경, G6은 동시성 변경, G7은 UI 변경, G8은 성능·감시 변경에 필수. 통합 시 전체 적용 가능한 게이트 재실행. 명령은 구현 예정 계약이며 현재 제공되지 않는다. 미구현 명령은 BLOCKED, 해당 없음은 QA 근거와 함께 N/A. sanitizer는 별도 빌드에서 실행한다. 로그와 SHA를 보존한다.

## UI/UX 디자인 권한
- 시각 디자인은 사용자가 Impeccable을 통해 별도로 제작한다. 에이전트는 색상, 타이포그래피, 간격, 레이아웃, 아이콘, 애니메이션, 테마 및 디자인 시스템을 임의로 정의하거나 변경하지 않는다.
- UI 기능 요구사항, 접근성, 상태 전달, GTK 바인딩 및 동작 테스트는 유지한다. 디자인 미제공 시 화면 스타일을 확정하지 말고 기능 로직과 인터페이스를 구현한다.
- 사용자가 제공한 디자인을 승인된 기준으로 적용하며 변경이 필요하면 먼저 승인을 요청한다. QA는 기능과 접근성을 검증하고 시각 디자인을 직접 수정하지 않는다.
