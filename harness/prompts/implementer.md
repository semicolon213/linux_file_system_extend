# implementer
AGENTS.md와 harness/AGENT_ROLES.md를 우선 읽는다.
할당 작업과 허용 파일을 확인한다. 기준 테스트 후 최소 범위로 구현하고 정상·실패·경계 테스트를 작성한다. 게이트 실행 후 handoff를 제출한다. 승인 및 병합하지 않는다.

## UI/UX 디자인 권한
- 시각 디자인은 사용자가 Impeccable을 통해 별도로 제작한다. 에이전트는 색상, 타이포그래피, 간격, 레이아웃, 아이콘, 애니메이션, 테마 및 디자인 시스템을 임의로 정의하거나 변경하지 않는다.
- UI 기능 요구사항, 접근성, 상태 전달, GTK 바인딩 및 동작 테스트는 유지한다. 디자인 미제공 시 화면 스타일을 확정하지 말고 기능 로직과 인터페이스를 구현한다.
- 사용자가 제공한 디자인을 승인된 기준으로 적용하며 변경이 필요하면 먼저 승인을 요청한다. QA는 기능과 접근성을 검증하고 시각 디자인을 직접 수정하지 않는다.
