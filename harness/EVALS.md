# 평가 시나리오

모든 파일 테스트는 mkdtemp 기반 격리 경로에서 수행한다. 종료 시 생성한 경로만 정리한다.
| ID | 시나리오 | 기대 결과 |
|---|---|---|
| E01 | 외부 파일 생성·수정·삭제 | 목록과 로그가 최종 상태 일치 |
| E02 | 디렉터리 이동·이름 변경 | 경로와 watch registry 갱신 |
| E03 | overflow 주입 | 이력 공백 표시, 재탐색 후 상태 일치 |
| E04 | 10,000 파일 탐색 | 기준 환경 1초 목표, UI 응답 유지 |
| E05 | 초당 1,000 이벤트 부하 | 유실 여부 기록, 최종 상태 일치 |
| E06 | 복사 중 취소·디스크 부족 | 원본 보존, 임시 파일 정리 |
| E07 | 외부 수정 중 편집 저장 | 충돌 경고, 무단 덮어쓰기 없음 |
| E08 | 악성 아카이브 경로 | 추출 대상 외 쓰기 없음 |
| E09 | 스냅샷 없는 삭제 | 복구 불가 명시 |
| E10 | 종료 중 worker 동작 | 안전 종료, 누수·경쟁 없음 |
성능은 OS, CPU, RAM, 파일 시스템, 캐시 상태, 반복 횟수와 P50/P95를 기록한다. 수치는 목표이며 측정 결과가 아니다. 필수 시나리오 실패 시 FAIL.
